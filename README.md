# StageConsole
A simple 512 DMX channel memory light board with unlimited cue memory and auto timed cross fades. Written in Python with standard libraries so that it will work cross platform on Windows, Mac and Linux.
 
This software is designed for conventional theatrical lighting. It works in a way that is easy to understand 
for a person who does theatrical lighting. It does not have features for moving lights, fancy chasing and nightclub-style control.

It has 4 Windows: 
* Playback - Go button to initiate crossfade to the next scene, displays progress of crossfade 
* Scenes - list of stored scenes with Number, Name, Fade In, Fade Out, Delay and Follow 
* Faders - sliders to set levels for 512 channels
* DMX Output Monitor displays current DMX levels

It requires an Enttec DMX USB Pro adapter to connect to a DMX lighting rig.
